# ApostilleXpress Customer Portal — deploy folder

Upload the CONTENTS of this folder (not the folder itself) to the root of your GitHub Pages repo.

- index.html redirects to the Login page (CustomerAuth.dc.html)
- .nojekyll must be present so GitHub Pages serves every file as-is
- Keep the assets/ and ds/ subfolders and all filenames exactly as they are (case-sensitive)
